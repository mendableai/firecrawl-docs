<div id="get-started">
  ## Primeiros passos
</div>

<Visibility for="humans">
  <McpClientSelector variant="human" />
</Visibility>

<Visibility for="agents">
  Conecte-se por Streamable HTTP. A URL do servidor sem chave (Busca, Scraping e Parse; sem necessidade de credenciais) é `https://mcp.firecrawl.dev/v2/mcp`.

  * Codex: `codex mcp add firecrawl --url https://mcp.firecrawl.dev/v2/mcp`
  * Claude Code: `claude mcp add --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp`
  * Cursor ou qualquer cliente com configuração JSON: `{"mcpServers": {"firecrawl": {"url": "https://mcp.firecrawl.dev/v2/mcp"}}}`
  * OpenCode (`opencode.json`): `{"mcp": {"firecrawl": {"type": "remote", "url": "https://mcp.firecrawl.dev/v2/mcp", "enabled": true}}}`
  * ChatGPT ou Claude.ai: use o conector nativo do Firecrawl — [ChatGPT](https://chatgpt.com/plugins?q=firecrawl) ou [Claude](https://claude.ai/directory/connectors/firecrawl).

  Ambos os modos de configuração e a configuração com chave de API: [Primeiros passos do MCP](/pt-BR/mcp-server.md), [Para agentes](/pt-BR/mcp-server/keyless.md) e [Para humanos](/pt-BR/mcp-server/oauth.md).
</Visibility>

<div id="install-the-firecrawl-cli">
  ### Instale a CLI do Firecrawl
</div>

Um único comando instala a CLI do Firecrawl, faz a autenticação no seu navegador e adiciona skills a todos os agentes de programação detectados.

```bash
npx -y firecrawl-cli@latest init --all --browser
```

<Note>
  Reinicie o seu agente de programação após a configuração para que ele possa descobrir as novas skills. Consulte
  [CLI](/pt-BR/sdks/cli) para o guia completo de configuração.
</Note>

<div id="why-firecrawl">
  ### Por que Firecrawl?
</div>

* **Resultado pronto para LLM**: Markdown limpo, JSON estruturado, capturas de tela e muito mais.
* **Lida com o mais difícil**: Proxies, anti-bot, renderização de JavaScript e conteúdo dinâmico.
* **Confiável**: Projetado para produção, com alta disponibilidade e resultados consistentes.
* **Rápido**: Resultados em segundos, otimizado para alto throughput.
* **MCP Server**: Conecte o Firecrawl a qualquer ferramenta de IA via [Model Context Protocol](/pt-BR/mcp-server).
