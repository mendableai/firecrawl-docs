此端点用于获取爬取任务的状态。若任务尚未完成，响应会在 `partial_data` 中返回内容。任务完成后，内容将位于 `data` 中。

**我们建议自行跟踪爬取任务，因为爬取状态结果可能会在 24 小时后过期。**
