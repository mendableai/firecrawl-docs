该 /search 端点将搜索 API 与 Firecrawl 的能力结合，为任意查询提供强大的搜索体验。

它会自动在全网执行搜索，并以 Markdown 格式返回来自排名靠前页面的最相关结果。此端点的优势在于会实际抓取这些结果页面上的网站内容，因此你始终能获得完整内容。

此端点目前为 Beta 版本，未来可能会变更。
