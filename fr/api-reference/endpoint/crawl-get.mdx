<Info>
  `total` compte les pages terminées, actives, en file d’attente et en attente de traitement, mais exclut les pages en échec : ainsi, `completed == total` sur un crawl terminé ne signifie pas que chaque page découverte a réussi. Associez ces compteurs à [Obtenir les erreurs d’un crawl](/fr/api-reference/endpoint/crawl-get-errors) pour repérer les pages tentées mais non retournées, et consultez [Exécution et comptabilisation des résultats](/fr/features/crawl#execution-and-result-accounting) pour savoir comment les interpréter conjointement et quand arrêter la pagination avec `next`.
</Info>
