<div id="searching-the-web-and-scraping-the-results-with-firecrawl">
  ## Rechercher sur le web et extraire les résultats avec Firecrawl
</div>

Firecrawl combine son API de recherche à son infrastructure de scraping robuste pour offrir, via un point de terminaison unique, une expérience fluide de recherche puis d’extraction. Voici comment :

1. **Requête de recherche unifiée :**
   Les utilisateurs soumettent une requête de recherche via le point de terminaison de recherche.

2. **Extraction automatisée des résultats :**
   Firecrawl traite automatiquement les résultats de recherche et utilise ses capacités de scraping pour extraire les données de chaque page de résultats.

3. **Livraison des données :**
   Les données extraites de toutes les pages de résultats sont compilées et fournies dans un markdown propre — prêtes à l’emploi.

Cette intégration permet d’effectuer des recherches web de manière efficace et d’obtenir, avec un effort minimal, des données complètes extraites depuis de multiples sources.

Pour plus de détails, consultez la [documentation du point de terminaison Search](https://docs.firecrawl.dev/api-reference/endpoint/search).

<div id="search-any-query">
  ## Rechercher n’importe quelle requête
</div>

<div id="search-endpoint">
  ### point de terminaison /search
</div>

Permet d’effectuer des recherches sur le web, d’obtenir les résultats les plus pertinents, de scraper chaque page et de renvoyer le markdown.

```bash
curl -X POST https://api.firecrawl.dev/v0/search \
    -H 'Content-Type: application/json' \
    -H 'Authorization: Bearer YOUR_API_KEY' \
    -d '{
      "query": "firecrawl",
      "pageOptions": {
        "fetchPageContent": true // false pour une API SERP plus rapide
      }
    }'
```

```json
{
  "success": true,
  "data": [
    {
      "url": "https://docs.firecrawl.dev",
      "markdown": "# Contenu Markdown",
      "provider": "web-scraper",
      "metadata": {
        "title": "Firecrawl | Explorez le Web de manière fiable pour vos LLM",
        "description": "IA pour l’expérience client et les ventes"
        "language": null,
        "sourceURL": "https://docs.firecrawl.dev/"
      }
    }
  ]
}
```

<div id="search-a-query-3">
  #### Effectuer une recherche
</div>

```go
import (
  "fmt"
  "log"

  "github.com/mendableai/firecrawl-go"
)

func main() {
  app, err := firecrawl.NewFirecrawlApp("YOUR_API_KEY")
  if err != nil {
      log.Fatalf("Failed to initialize Firecrawl: %v", err)
  }

  query := "Qu'est-ce que Firecrawl ?"
  searchResult, err := app.Search(query)
  if err != nil {
    log.Fatalf("Failed to search: %v", err)
  }
  fmt.Println(searchResult)
}
```
