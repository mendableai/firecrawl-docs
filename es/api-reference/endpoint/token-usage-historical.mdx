Devuelve el uso histórico de tokens por mes. Este endpoint también puede desglosar el uso por clave de API de forma opcional.

<Info>Hemos simplificado la facturación para que Extract ahora use créditos, igual que los demás endpoints. Cada crédito equivale a 15 tokens. El uso de tokens informado ahora incluye el uso de todos los endpoints.</Info>
