Firecrawl ofrece diferentes tipos de proxy para ayudarte a extraer datos de sitios web con distintos niveles de complejidad. Puedes especificar el tipo de proxy con el parámetro `proxy`.

> De forma predeterminada, Firecrawl dirige todas las solicitudes a través de proxies para garantizar la fiabilidad y el acceso, incluso si no especificas un tipo de proxy o una ubicación.

<div id="how-to-specify-proxy-location">
  ## Cómo especificar la ubicación del proxy
</div>

Puedes solicitar una ubicación de proxy específica estableciendo el parámetro `location.country` en tu solicitud. Por ejemplo, para usar un proxy de Alemania, configura `location.country` en `DE`.

Para ver todos los detalles, consulta la [referencia de la API de `location.country`](https://docs.firecrawl.dev/api-reference/endpoint/scrape#body-location).

<div id="proxy-types">
  ## Tipos de proxy
</div>

<Warning>
  El parámetro `proxy` está obsoleto. Recomendamos `auto` —el valor predeterminado—, que permite a Firecrawl gestionar la selección de proxy por ti.
</Warning>

* **basic**: Proxies para hacer scraping de la mayoría de los sitios.
* **enhanced**: Proxies enhanced para hacer scraping de sitios complejos manteniendo la privacidad. [Más información sobre Enhanced Mode →](/es/features/enhanced-mode)
* **auto**: Recomendado. Firecrawl reintentará automáticamente el scraping con proxies enhanced si el proxy básico falla.
