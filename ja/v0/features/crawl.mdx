Firecrawl はウェブサイトを徹底的にクロールし、複雑な Web インフラに対応しながら網羅的にデータを抽出します。動作は次のとおりです。

1. **URL 分析:**
   指定した URL を起点に、サイトマップを参照してリンクを特定し、サイトをクロールします。サイトマップが見つからない場合は、ページ内リンクをたどってクロールを進めます。

2. **再帰的な走査:**
   すべての下層ページを見つけるために各リンクを再帰的に辿ります。これは v0 のクロールモデルのみについての説明です。現在のクロールが URL をどのように検出・網羅するかは [クロール](/ja/features/crawl) を参照してください。

3. **コンテンツのスクレイピング:**
   JavaScript レンダリングやレート制限などの複雑さに対処しつつ、訪問したすべてのページからコンテンツを収集します。

4. **結果の整形:**
   収集したデータをクリーンな Markdown または構造化された出力に変換し、LLM の処理やその他のタスクに最適化します。

この手法により、任意の開始 URL からの網羅的なクロールとデータ収集を実現します。

  ## クロール
</div>

<div id="crawl-endpoint">
  ### /crawl エンドポイント
</div>

指定した URL とアクセス可能なサブページをクロールします。クロールジョブを送信し、進行状況を確認するためのジョブ ID を返します。

<div id="usage">
  ### 使い方
</div>

<CodeGroup>
  ```python Python
  from firecrawl import Firecrawl

  app = Firecrawl(api_key="YOUR_API_KEY")

  crawl_result = app.crawl_url('mendable.ai', {'crawlerOptions': {'excludes': ['blog/*']}})

  # Markdown を取得
  for result in crawl_result:
      print(result['markdown'])
  ```

  ```js JavaScript
  import { Firecrawl } from 'firecrawl';

  // API キーで Firecrawl を初期化
  const app = new Firecrawl({ apiKey: 'YOUR_API_KEY' });

  // サイトをクロール
  const crawlResult = await app.crawlUrl('mendable.ai', { crawlerOptions: { excludes: ['blog/*'] } });

  // Markdown をログ出力
  console.log(crawlResult.map(result => result.markdown));
  ```

  ```go Go
  import (
    "fmt"
    "log"

    "github.com/mendableai/firecrawl-go"
  )

  func main() {
    app, err := firecrawl.NewFirecrawlApp("YOUR_API_KEY")
    if err != nil {
      log.Fatalf("Firecrawl の初期化に失敗しました: %v", err)
    }

    crawlResult, err := app.CrawlURL("mendable.ai", nil)
    if err != nil {
      log.Fatalf("URL のクロールに失敗しました: %v", err)
    }

    fmt.Println(crawlResult)
  }
  ```

  ```rust Rust
  use firecrawl::Firecrawl;

  #[tokio::main]
  async fn main() {
    // API キーで Firecrawl を初期化
    let api_key = "YOUR_API_KEY";
    let api_url = "https://api.firecrawl.dev";
    let app = Firecrawl::new(api_key, api_url).expect("Firecrawl の初期化に失敗しました");

    // URL をクロール
    let crawl_params = json!({
      "crawlerOptions": {
          "excludes": ["blog/*"]
      }
    });

    let crawl_result = app
        .crawl_url("https://example.com", Some(crawl_params), true, 2, None)
        .await;

    // クロール結果を出力
    match crawl_result {
        Ok(data) => println!("Crawl Result:\n{}", data),
        Err(e) => eprintln!("クロールに失敗しました: {}", e),
    }
  }
  ```

  ```bash cURL
  curl -X POST https://api.firecrawl.dev/v0/crawl \
      -H 'Content-Type: application/json' \
      -H 'Authorization: Bearer YOUR_API_KEY' \
      -d '{
        "url": "https://mendable.ai"
      }'
  ```
</CodeGroup>

<div id="job-id-response">
  ### ジョブIDレスポンス
</div>

SDKを使わない場合、またはWebhookや別のポーリング方法を使いたい場合は、`wait_until_done` を `false` に設定します。
この場合、`jobId` が返されます。

cURLでは、/crawl は常に `jobId` を返し、それを使ってクロールのステータスを確認できます。

```json
{ "jobId": "1234-5678-9101" }
```

<div id="check-crawl-job">
  ### クロールジョブの確認
</div>

これにより、クロールジョブのステータスを確認し、その結果を取得できます。

<CodeGroup>
  ```python Python
  status = app.check_crawl_status(job_id)
  ```

  ```js JavaScript
  const status = await app.checkCrawlStatus(jobId);
  ```

  ```go Go
  status, err := app.CheckCrawlStatus(jobId)
  if err != nil {
    log.Fatalf("Failed to check crawl status: %v", err)
  }
  ```

  ```rust Rust
  let status = match app.check_crawl_status(jobId).await {
      Ok(status) => status,
      Err(e) => panic!("Failed to check crawl status: {:?}", e),
  };

  println!("Crawl Status: {:?}", status);
  ```

  ```bash cURL
  curl -X GET https://api.firecrawl.dev/v0/crawl/status/1234-5678-9101 \
    -H 'Content-Type: application/json' \
    -H 'Authorization: Bearer YOUR_API_KEY'
  ```
</CodeGroup>
