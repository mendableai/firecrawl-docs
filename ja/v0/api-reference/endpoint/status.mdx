このエンドポイントは、クロールジョブのステータスを取得します。ジョブが未完了の場合、レスポンスの `partial_data` にコンテンツが含まれます。完了後は、コンテンツは `data` に格納されます。

**クロールステータスは24時間で失効する場合があるため、クロールジョブはご自身で管理することを推奨します。**
